# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [0.2.0]

### Added

- Blessing of the Waterways: Immersion buff (water breathing, faster underwater movement and mining) granted upon discovering all 5 well types
- "Wells Explored" advancement for visiting all well structures
- Minecraft 1.21.11 support (Fabric + NeoForge)
- Minecraft 1.21.10 support (Fabric + NeoForge)
- Minecraft 1.21.9 support (Fabric + NeoForge)
- Minecraft 1.21.8 support (Fabric + NeoForge)
- Minecraft 1.21.7 support (Fabric + NeoForge)
- Minecraft 1.21.6 support (Fabric + NeoForge)
- Minecraft 1.21.5 support (Fabric + NeoForge)
- Minecraft 1.21.4 support (Fabric + NeoForge)
- Minecraft 1.21.3 support (Fabric + NeoForge)

### Changed

- Removed Architectury API runtime dependency

## [0.1.0]

### Added

- Weathered wells that generate naturally in the world (5 structure variants)
- Sunken wells that spawn submerged in water
- Totem items found in well chests
- Blessing of the Waterways buff (healing + regeneration) from collecting totems
- Custom healing particle effects for water buff
- Advancements for well discovery and totem collection
- Buff effects persist across sessions and restore on respawn
- Minecraft 1.21.1 support (Fabric + NeoForge)
- Minecraft 1.20.1 support (Fabric + Forge)

### Fixed

- Buff effects not restoring on player respawn
- Water leaking from well structures
